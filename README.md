# Real-Time Forest Fire & Smoke Detection

An end-to-end deep learning computer vision system for detecting forest fire and smoke from images, videos, and real-time camera streams.

## Project Goal

The system will:

- Detect fire and smoke using YOLO object detection
- Evaluate the model using Precision, Recall, F1-score and mAP
- Perform real-time inference using OpenCV
- Reduce false alarms using temporal verification
- Provide inference through a FastAPI backend
- Display results through a Streamlit dashboard
- Support Docker-based deployment

## Technology Stack

- Python
- PyTorch
- YOLO
- OpenCV
- FastAPI
- Streamlit
- Docker
- Git / GitHub
